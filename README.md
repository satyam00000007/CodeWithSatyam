# Satyam Sharma Portfolio

A responsive Angular portfolio based on Satyam Sharma's May 2026 resume. It highlights measurable engineering impact, selected projects, experience, and technical expertise.

## Run locally

```bash
npm install
npm start
```

Open `http://localhost:4200`.

## Production build

```bash
npm run build
```

The production output is written to `dist/satyam-portfolio`.

## Customize

- Portfolio content and project data: `src/app/app.component.ts`
- Page structure: `src/app/app.component.html`
- Visual design and responsive styles: `src/app/app.component.scss`
- Global styles and fonts: `src/styles.scss`
